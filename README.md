### 🏢 Ajke Technology — Senior Software Engineer
**`Nov 2024 – Present`** · Dhaka, Bangladesh

- Owns backend architecture for a high-concurrency quick-commerce and fleet platform — service boundaries, data model, reliability, and release pipelines; leading 4 engineers
- Designed distributed NestJS backend on PostgreSQL + Redis + BullMQ — thousands of daily transactional events with idempotent, queue-based flows and at-least-once delivery guarantees
- Architected **Ryoko Reseller Platform** — multi-tenant OTA for 100+ resellers with LLM-based document intelligence, real-time status pipelines, and RBAC for compliance-sensitive data
- Engineered zone-based dynamic pricing and automated rider-assignment algorithms → **~20% logistics efficiency gain**
- Hardened CI/CD with GitHub Actions + Docker + Kubernetes on DigitalOcean — standardized build, release, and rollback flows
